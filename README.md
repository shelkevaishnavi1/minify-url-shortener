# Minify — URL Shortener

A full-stack URL shortening application built to understand and implement the core concepts behind a real-world URL shortener system.

The project allows users to convert long URLs into short, easy-to-share links and automatically redirects users to the original URL when the short link is accessed.

---

## 🚀 Features

- 🔗 Convert long URLs into short URLs
- ⚡ Fast URL redirection
- 🆔 Generate unique short URL identifiers(used nanoid hashfunction)
- ⏳ URL expiration support
- 🛡️ Validate URLs before creating short links
- 🔄 Handle short URL collisions
- 🗄️ Store URLs using MySQL
- 🌐 REST API architecture
- 💻 Modern React/Next.js frontend
- 🖥️ Express.js backend
- 📦 Sequelize ORM
- 🔐 Environment variable configuration
